# Personal Website

## Install

This project is using [Sass](https://sass-lang.com/). To install Sass on your machine run the following command:

```
npm install -g sass
```
## Compile scss files to css

Run the following commands in the root folder to compile .scss file to .css

For `styles.scss`:
```
sass styles/scss/styles.scss styles/css/styles.css
```

For `imprint.scss`:
```
sass styles/scss/imprint.scss styles/css/imprint.css
```
